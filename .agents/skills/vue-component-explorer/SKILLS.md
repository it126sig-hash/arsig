# SKILL: Vue 3 UI Components & Explorer

## CONTEXT
Membangun Single Page Application (SPA) Vue 3 untuk web browser dan Capacitor WebView.

## RULES & CONSTRAINTS
1. **Arsitektur Kode:** Wajib menggunakan Vue 3 Composition API (`<script setup>`). Dilarang menggunakan Options API.
2. **Estetika Desain:** Terapkan gaya visual *clean*, minimalis modern, dan elegan. Hindari elemen UI yang terlalu padat atau *cluttered*. Gunakan *utility classes* Bootstrap 5 dengan hierarki *whitespace* yang rapi.
3. **Mobile-First:** Pastikan struktur UI dan *layout* sepenuhnya responsif dan optimal saat diakses melalui Android WebView.
4. **State Management:** Navigasi hierarki arsip (File Explorer) harus terasa instan menggunakan *state management* (Pinia), hindari *full page reload*.
